# Interactive Explainer Series

Interactive lessons in computer science, statistics, and mathematics, with visual widgets, explanations, examples, and practical code.

## Browse the site

The website starts at docs/index.html. Its navigation follows:

Home → Machine learning → Supervised learning → Regression or Classification → Interactive lesson

Regression includes Simple Linear Regression, Polynomial Regression, and Regularization.
Classification includes Logistic Regression, K-Nearest Neighbors, Decision Trees, Random Forests, Support Vector Machines, and XGBoost.

## Project structure

- docs/index.html: main learning catalog.
- docs/machine-learning/index.html: machine learning overview.
- docs/machine-learning/supervised-learning/index.html: regression and classification overview.
- docs/machine-learning/supervised-learning/regression/: topic landing page and three lesson folders.
- docs/machine-learning/supervised-learning/classification/: topic landing page and six lesson folders.
- docs/assets/css/: shared catalog styles and lesson navigation styles.
- docs/.nojekyll: serve the static files without Jekyll processing.
- docs/deep-learning/: interactive neural-network foundation, training loop, and architecture overview.

Each published topic and lesson has an index.html. Lesson URLs use lowercase, hyphenated folder names. All site links are relative so the site works beneath a GitHub repository URL prefix.

The original machine-leaning directory has been corrected to machine-learning inside docs. Existing long HTML filenames have been replaced by lesson folders; update any bookmarks to the new catalog URLs.

## Preview locally

From the repository root, with Python installed:

    python3 -m http.server 8000

Open http://localhost:8000/docs/ in a browser. Serving the repository rather than docs also checks that links work beneath a URL prefix.

## Publish on GitHub Pages

1. Push the changes to the repository's master branch.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select master and /docs, then Save.

For a project repository, the site will be available at:
https://<owner>.github.io/<repository>/

No build process or package installation is required. Publishing is configured in GitHub; reorganizing the local files does not enable Pages automatically.

## Add a lesson

1. Create docs/machine-learning/supervised-learning/<topic>/<lesson-slug>/index.html.
2. Include a doctype, lang="en", UTF-8 charset, page title, and viewport metadata.
3. Keep lesson-specific assets beside the lesson; put shared assets in docs/assets/.
4. Link the lesson from its topic landing page.
5. Add breadcrumbs and update adjacent lessons' previous/next links.
6. Check the page, interactive controls, and all navigation using the local server.

The existing lessons retain their embedded styles and scripts. Shared navigation uses a separate stylesheet to avoid changing lesson behavior.

This collection is a work in progress; existing lessons may be expanded and additional topics added.
## Interactive homepages

Six guides provide diagrams, mathematical explanations, and browser-local experiments:

- Interactive Series: compare regression, classification, and clustering.
- Machine Learning: fit polynomial models and compare training versus held-out error.
- Supervised Learning: explore sample size, complexity, and evaluation discipline.
- Regression: fit a line, inspect residuals, and compare MSE with MAE.
- Classification: change the threshold and inspect precision, recall, and confusion counts.
- Deep Learning: inspect a fixed neural network's activations and output probability.

The homepage content and shared HTML template are maintained in
scripts/build_homepages.py. After editing it, regenerate the six pages:

    python3 scripts/build_homepages.py

The generated HTML is committed under docs; GitHub Pages needs no build step.
Shared presentation lives in docs/assets/css/site.css and interactive behavior in
docs/assets/js/homepages.js. The nine existing lesson files are not generated by
this script. Animations respect reduced-motion preferences and can be paused.
All example datasets are synthetic; the neural-network demonstration uses fixed,
illustrative weights rather than a trained model.
