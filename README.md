# interactive-explainer-series

## What is the intent of this repository

- This reporitory is intended to be published as GitHub Pages sites.
- In this interactive explainer series, there are single page html sites on various topics reated to computer science, statistics and mathematics
- every topic is dedicated one or more html pages that are loaded with
    - interactive widgets for every mathematical & statistical concept
    - simplified mathematical and statistical explainers
    - detailed descriptions with examples
    - practical code examples (if applicable)
    - tips and tricks, industry common practices
    - complete and comprehensive coverage
    - consistent table-of-contents and template

This repository is work in progress. many topics and their content are yet to be created and the existing ones will undergo major updates and more content.
