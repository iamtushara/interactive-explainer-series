04 / A shared language

Four things to keep separate.

Data and representation

A dataset contains observations. A feature is the representation you expose to the model: age, a word count, a pixel value, or an embedding. A target is the answer you want the model to predict. A good representation makes useful structure accessible; a misleading one can encode leakage or irrelevant shortcuts.

Model and parameters

A model family specifies the rules you allow. Parameters are the values learned within that family. A straight line has a slope and an intercept; a neural network has weight matrices and bias vectors. Choosing a richer family gives the optimizer more freedom, not a guarantee of better predictions.

Objective and optimization

The loss assigns a cost to a prediction. Optimization searches for parameter values that reduce that cost. Squared error punishes large numerical mistakes; log loss penalizes assigning low probability to the observed class. Your objective is a modeling decision, not a universal definition of usefulness.

Evaluation and generalization

A model can remember the examples it sees. The real question is whether it works on examples it has not used to learn or tune itself. Keep training, validation, and final testing distinct, and ask whether the evaluation data represents the environment where predictions will be used.

05 / Go one layer deeper

The common mathematical thread.

Empirical risk: turning examples into an objective
θ̂ = arg minθ [ (1/n) Σᵢ ℓ(fθ(xᵢ), yᵢ) + λΩ(θ) ]

Here xᵢ is an input, yᵢ its target, f is the model, ℓ is a per-example loss, and Ω penalizes complexity. λ controls the strength of that penalty. This supervised-learning template covers many models, but not every learning problem.

Why a beautiful fit can be a bad model

Observed data mixes signal with sampling variation and noise. A flexible model can fit both. Training error measures agreement with known examples; generalization error concerns new examples from a relevant distribution. A low training loss alone establishes neither robustness nor causal understanding.
