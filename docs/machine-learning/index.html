Start with a baseline

A simple constant, linear model, or small tree establishes whether extra complexity buys anything. Compare against the same split and metric. A sophisticated model that cannot beat a sensible baseline may be learning noise or optimizing the wrong objective.

Choose the right split

A random split assumes observations can reasonably be treated as exchangeable. Time series usually need chronological evaluation. Repeated observations from a patient, customer, or device often need grouped splits. Otherwise information can flow between sets and inflate performance.

05 / Under the hood

Capacity is only half the story.

Bias, variance, and irreducible noise
Expected squared error = bias² + variance + noise

For squared-error prediction at a fixed input, under a standard additive-noise setup, this decomposition averages over possible training datasets. Bias is systematic mismatch; variance is sensitivity to the sample. The playground uses one fixed sample, so it illustrates the trade-off rather than estimating this decomposition.

Regularization and the effective model
Objective = mean training loss + λ × penalty

Regularization changes which solutions are preferred. L2 penalties discourage large weights; other constraints, early stopping, and data augmentation can also shape effective complexity. Scaling features matters when a penalty depends on coefficient magnitude.

Validation is a limited resource

Repeatedly choosing models based on the same validation set gradually adapts your choices to it. Keep a final test set for a one-time assessment after the procedure is fixed. Cross-validation can improve estimates for small datasets, but preprocessing must be fitted within each fold.

Prediction is not causation

A feature can predict an outcome because of a common cause, selection effects, or a proxy relationship. Changing that feature may not change the outcome in the predicted way. Causal claims require additional assumptions and an appropriate study design.
