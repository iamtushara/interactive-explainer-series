03 / Know the cost of being wrong

There is more than one kind of mistake.

False positives and false negatives

A false positive predicts the positive class when the actual class is negative. A false negative misses an actual positive. In spam filtering, a false positive may hide a legitimate message; a false negative lets spam through. The best operating point depends on these consequences, not just an arbitrary threshold of 0.5.

Precision and recall

Precision asks: among the predicted positives, how many are actually positive? Recall asks: among all actual positives, how many did we detect? Raising a threshold can reduce the number of positive predictions, but precision need not move monotonically in a finite sample.

Accuracy can conceal failure

If positives are rare, predicting the majority class can achieve high accuracy while detecting none of the cases you care about. Inspect the confusion matrix, per-class performance, and the base rate. For imbalanced tasks, precision–recall behavior is often especially informative.

Calibration answers another question

Among cases assigned a probability near 0.8, roughly 80% should be positive if the model is well calibrated on that population. Good ranking does not imply calibration. Probability quality and threshold choice must be evaluated separately.

04 / Under the hood

From a score to a probability.

Logistic regression: a linear log-odds model
z = wᵀx + b
p(y = 1 | x) = σ(z) = 1 / (1 + e−z)
log[p / (1−p)] = wᵀx + b

The sigmoid maps a real-valued score to (0,1). A fixed threshold produces a linear boundary in the chosen feature representation. Adding nonlinear features can make the boundary nonlinear in the original inputs.

Cross-entropy rewards honest probabilities
ℓ(p,y) = −y log p − (1−y) log(1−p)

A confidently wrong prediction incurs a large loss. Unlike accuracy, this loss responds to probability changes even when the predicted label stays the same. Implementations should use numerically stable logit-based computations rather than taking logs of rounded probabilities.

The confusion matrix and derived metrics
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2TP / (2TP + FP + FN)

Each metric summarizes a different trade-off. Precision is undefined when no positive predictions are made; recall is undefined when there are no actual positives. F1 combines precision and recall but ignores true negatives and does not encode every application’s error costs.

Multiclass versus multilabel

Multiclass classification chooses one among several mutually exclusive categories, often using softmax probabilities. Multilabel classification allows multiple labels per example, often using a separate sigmoid output for each label. The target representation, loss, and metrics must match the task.
