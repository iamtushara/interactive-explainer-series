Labels define the question

“Will this customer leave within 30 days?” and “How many days until the customer leaves?” use similar inputs but imply different targets, losses, and evaluation. Write down the prediction horizon and how labels are collected before choosing an algorithm.

Labels can be imperfect

Annotation disagreement, missing outcomes, delayed feedback, and historical decisions can affect the targets. A model learns patterns in recorded labels; it does not automatically recover an ideal, unbiased ground truth. Inspect how labels were produced and which cases are absent.

05 / The objective

Learning as risk minimization.

What exactly gets minimized?
R̂(θ) = (1/n) Σᵢ ℓ(fθ(xᵢ), yᵢ)

The empirical risk averages loss over observed examples. Minimizing it approximates minimizing expected loss on future examples only when the data and modeling assumptions support that transfer. Regularization adds preferences about plausible solutions.

Parameters versus hyperparameters

Parameters are fitted from training data: slopes, tree splits, or network weights. Hyperparameters configure the procedure: tree depth, neighbor count, regularization strength, or learning rate. Hyperparameters are usually chosen using validation performance; the test set must not become a tuning loop.

Common losses for different outputs
Regression: ℓ = (y − ŷ)²
Binary classification: ℓ = −y log p − (1−y) log(1−p)

Squared error emphasizes large residuals. Binary cross-entropy evaluates probabilities assigned to binary labels. The probability threshold used to make a hard decision is a separate choice from the loss used to learn probabilities.

Distribution shift breaks easy assumptions

Future inputs, label frequencies, or the relationship between input and target can change. A test score is evidence about a particular evaluation distribution. Monitor meaningful slices and changes over time, and decide when recalibration or retraining is needed.
