03 / Read the model

A slope is a statement about change.

Slope and intercept

In ŷ = mx + b, the slope m is the predicted change in the target for one unit of x. The intercept b is the predicted target at x = 0. An intercept may be mathematically necessary even when zero lies outside the meaningful input range. With multiple features, each coefficient is interpreted conditional on the other included features.

Residuals are evidence

A residual is the observed target minus the prediction: e = y − ŷ. A visible curve in residuals suggests missing nonlinear structure. A widening spread suggests nonconstant variance. Large residuals deserve investigation; they can be valid rare cases, data errors, or signs that the model is inappropriate.

Interpolation versus extrapolation

Predicting inside the observed input range is interpolation. Predicting outside it is extrapolation, where the chosen functional form does much more of the work. A polynomial can look convincing in-range and diverge rapidly beyond the data. Always inspect the domain where a prediction is being requested.

Association is not an intervention

A positive coefficient does not prove that increasing the feature causes the target to increase. Confounding and selection can create predictive relationships without that causal meaning.

05 / From intuition to equations

What least squares is doing.

Derive the best-fitting line
m̂ = Σᵢ(xᵢ − x̄)(yᵢ − ȳ) / Σᵢ(xᵢ − x̄)²
b̂ = ȳ − m̂x̄

Set the derivatives of the sum of squared residuals with respect to m and b to zero. The denominator must be nonzero: if all x values are identical, slope and intercept are not separately identifiable. The playground’s fit button uses this closed-form solution.

Polynomial regression is still linear in its parameters
ŷ = β₀ + β₁x + β₂x² + ⋯ + βₖxᵏ

The curve is nonlinear in x, but the prediction is a linear combination of learned coefficients. You can fit it with linear least squares on transformed features. High-degree power bases can also be numerically ill-conditioned; feature scaling and better-conditioned bases matter.

Ridge and Lasso change the objective
Ridge: mean squared error + λΣⱼβⱼ²
Lasso: mean squared error + λΣⱼ|βⱼ|

Ridge shrinks coefficients smoothly. Lasso can set some coefficients exactly to zero. The intercept is commonly left unpenalized, and scaling features is important for comparable penalties. ElasticNet combines both penalties. Select λ with validation, not final test performance.

Fitting versus statistical inference

Least squares can be computed without Gaussian noise. Stronger assumptions matter for properties of estimators, standard errors, and prediction intervals. Normality, independence, constant variance, and correct mean specification play different roles; a point prediction alone does not quantify uncertainty.
